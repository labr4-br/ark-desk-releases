## O que você contrata

Você não conversa com um assistente esperando que ele acerte. Você escolhe um
serviço que **já existe** — com o processo desenhado, os limites escritos e as
aprovações definidas antes de qualquer coisa acontecer.

|  | |
|---|---|
| 🏢 &nbsp;**Departamento** | Onde o trabalho mora. Engenharia, Marketing, Financeiro — cada um com os seus processos. |
| ⌘ &nbsp;**`/`** | Como se contrata. Abre o catálogo do departamento e você escolhe o serviço. |
| 📋 &nbsp;**Pedido** | Uma contratação, com começo e fim. Não é mais uma mensagem num fio infinito. |
| 🧾 &nbsp;**Recibo** | A prova do que foi feito — inclusive do que a revisão recusou. |

<br>

## Como funciona

<div align="center">

**Contratar** → **Entrevistar** → **Operar** → **Aprovar** → **Receber**

</div>

<br>

**1. Contratar.** Você escolhe um serviço do catálogo. O escopo, os limites e o
que ele não faz já estão no cartão — nada é inventado a partir do que você
escreveu.

**2. Entrevistar.** O serviço pergunta até ter o que precisa. Três respostas
possíveis, e você vê qual foi:

- ✅ &nbsp;**Pronto para começar**
- ⏸ &nbsp;**Falta alguma coisa** — a entrevista continua
- ⊘ &nbsp;**Não há o que fazer** — já está feito, ou não se aplica

**3. Operar.** O pedido mostra a etapa, o bloqueio e o que falta de você. Sem
muro de texto passando na tela.

**4. Aprovar.** Quando o serviço exige, vira fila: rascunho, proposta de
mudança, publicação. Nada sai sem você.

**5. Receber.** Resultado e recibo. O pedido fecha.

<br>

## Por que é diferente

|  |  |
|---|---|
| **A revisão que recusa** | Quem executa não se autoaprova. Outra identidade revisa, e o que ela recusou aparece no recibo. |
| **Você aprova antes de publicar** | Merge, deploy e publicação continuam humanos. Autonomia que publica sozinha fica desligada. |
| **Recibo, não "pronto!"** | O que rodou, o que foi recusado, o que você aprovou. Dá para mostrar a um sócio. |
| **Não inventa trabalho** | Se não há o que fazer, o Ark Desk diz isso — em vez de produzir algo para parecer útil. |

### Primeira execução

Os instaladores ainda não são assinados, então o sistema pede uma confirmação
a mais na primeira vez:

- **Windows** — o SmartScreen mostra *"editor desconhecido"*: **Mais informações → Executar assim mesmo**
- **macOS** — o Gatekeeper recusa o duplo clique: **botão direito no app → Abrir**, e confirmar

Uma vez só. Depois disso o app abre normalmente.
